// 基礎

AI 是怎麼「看」東西的？

物件偵測＝ 在照片裡框出物體，並說出它是什麼。

AI 靠的是從大量照片學到的「特徵」：邊緣、形狀、明暗、顏色。

天氣一變，這些特徵就變了——但 AI 只看過晴天的樣子。
背景知識Wiki：C1 天氣如何讓影像變差

// 問題

不同天氣，破壞的東西不一樣

🌫️ 霧

光在空氣中散射，越遠越白，對比變低。

S5

🌧️ 雨

雨絲讓畫面變白、對比下降；擋風玻璃上的雨滴一直變形。

S4

🌙 夜晚

整張圖變暗，細節消失；研究用 xγ 模擬變暗。

S2

❄️ 雪・沙塵

真實資料集 DAWN 收錄；沙塵讓某些方法更難。

S3 · S6

共同點：偵測器靠的邊緣與對比被破壞了，而且小東西最先看不見。
來源 S2 S3 S4 S5 S6Wiki：C1 天氣如何讓影像變差

// 動手看看

霧有公式：越遠、越濃，就越看不見

I = R·t + L·(1 − t)

I：拍到的影像　R：清晰的場景　L：霧的亮度（大氣光）
t = e−β·距離：能穿過霧的光的比例

選一個霧的濃度 β：

能見度 ≈ 2.996 ÷ β ＝ —

研究用這 5 種 β 合成霧，對應能見度約 600、300、150、100、50 m。

來源 S5（Koschmieder 模型、5 種 β）Wiki：C1 · S5

為什麼？

  • 修圖的目標是「人看起來清楚」，不是「AI 好認」
  • 修圖時把物體邊緣也磨平了
  • 修圖模型用合成雨訓練，遇到真雨就失準
霧也一樣：去霧前處理沒有一致的幫助（S5）。
看起來清楚 ≠ 偵測準確

// 路線二：讓偵測器自己學修圖

IA-YOLO：修圖的目標改成「讓偵測更準」

DIP 是可訓練的修圖濾鏡；CNN-PP 決定每張圖要修多少；兩者和 YOLOv3 一起訓練。

測試資料（mAP）原始 YOLOv3IA-YOLO
合成霧（VOC_Foggy）31.0572.03
真實霧（RTTS）28.8237.08
真實夜間（ExDark）36.4240.37

代價：每張圖多約 13 ms。後續的 ERUP-YOLO 改用通用濾鏡，雪天進步很多，但沙塵反而變差（S6）。

// 路線三：從資料下手

真實壞天氣的照片太少，怎麼辦？

🧪 合成：在晴天照片上「加天氣」

用霧的公式加霧（S5）：真實霧天的分割準確度（mIoU）34.9% → 37.8%。

IA-YOLO 讓 2/3 的訓練圖加上霧或變暗（S2）。

便宜、量大，但和真實天氣有落差。

📷 真實：收集並標註

DAWN：1,000 張真實霧、雪、雨、沙塵交通照片，7,845 個框（S3）。

Foggy Driving：101 張真實霧天照片，只用來測試（S5）。

貴、慢，但最可信。

常見做法：合成資料拿來訓練，真實資料拿來測試。作者甚至認為「缺資料」才是最根本的問題（S4）。
來源 S2 S3 S4 S5Wiki：C4 合成 vs 真實資料

// 路線四：換一雙眼睛

熱成像：看的是「熱」，不是光

一般相機需要光；熱成像（長波紅外線）拍的是物體自己發出的熱，所以夜晚、霧、雨中都看得到人。

RGB 預訓練直接用
19.63
只用晴天熱影像訓練
79.39
熱影像（含各天氣）訓練
97.93

夜間行人偵測 AP（%），YOLOv3（S1）

要注意

  • 換了感測器，模型也要重新訓練
  • 霧的影響比雨大
  • 只在一個地點、冬天夜晚測試
  • 車牌的字沒有溫差，熱影像可能讀不出車牌（待查證）
來源 S1 Kristo et al.Wiki：C5 熱成像

// 怎麼知道真的有變好？

公平評估的 4 個原則

① 分天氣報告

晴、雨、霧、夜各算一次，不要只給平均

② 晴天也要測

改善雨天，不能讓晴天變差

③ 用真實照片測

只測合成資料會太樂觀

④ 報告速度

修圖模組會多花時間

⚠ 陷阱：同一個 YOLOv3 在 RTTS 上，一篇論文報 28.82，另一篇報 49.01。設定不同的數字不能放在一起比。
來源 S2 S4 S6Wiki：C6 如何評估

// 和我的研究有什麼關係

車牌：又小、又要讀字

我在自己做的「車牌辨識實驗室」用一般 OCR（文字辨識）測了 4 張車牌：

情況結果
清楚、正拍（2 張）✓ 完全正確
夜間、傾斜（2 張）✗ M→N、K→X、Q 不見

整串正確 50%　字元正確 86%

從四條路得到的啟示

  • 不要只靠「先修圖」
  • 修圖要和辨識一起訓練
  • 收集台灣／越南真實雨夜車牌當測試集
  • 結果依天氣分組報告

// 總結

帶走三句話

  • 惡劣天氣破壞對比與邊緣，小物件最先受害
  • 看起來清楚 ≠ 偵測準確：修圖要以偵測為目標
